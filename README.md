# Creative Coding

Interactive browser sketches. Each folder is a standalone `index.html` — open it in a browser, no build step.

| Folder | Sketch |
|---|---|
| `game-of-life-2d/` | Conway's Game of Life on a 2D grid; tap to place gliders, spaceships, pulsars, Gosper gun |
| `game-of-life-3d/` | 3D Game of Life (Three.js): six lattice types, Generations-style decay, colour by creature, touch rotate/zoom |
| `image-slicer/` | Slice an image into strips or rings, drag and animate the slices, export the result |
| `swarm/` | 3D boids swarm (Three.js) in a box, sphere, pyramid, torus or uploaded mesh (OBJ/STL/PLY/GLB); trails, hue, attractor, rotate/zoom |
